# Getting started

## Install

1. Download `Boshsu-1.3-clean.zip` from [Releases](https://github.com/hsob2nd/Boshsu/releases).
2. Extract the entire archive into a folder you can write to. Settings and player data are stored beside the client.
3. Run `Boshsu.exe`. Keep the DLLs, materials, fonts, models, shaders and helper folders beside it.
4. Use Profile to choose your display name and avatar. Renaming changes the displayed identity of the same profile; it does not create another account.
5. In Options, configure your Songs library and select your skin. The clean package contains no maps or custom skins.

The binary targets Windows x64 and .NET Framework 4.8. Linux launch and every hardware/driver combination are unqualified. The source build has separate development dependencies; players do not need those tools or a separate calculator installation.

## Display and input

The first launch uses the primary monitor, its native resolution, fullscreen and the Main Menu. Subsequent monitor/window/resolution choices are saved. Use the display settings for fullscreen, windowed or a smaller centered gameplay area where configured.

Review your keyboard, mouse and tablet bindings in Options before playing. The configured bindings are authoritative. `Esc` provides the usual back/pause flow unless the corresponding gameplay binding was changed. HUD, FPS, gamma and playfield presentation options are available independently of the skin.

## Your first play

Select a local Standard difficulty, choose your mods and assistance settings, then play. Completion returns a local Results view with the captured score/accuracy/combo, PP, FC estimate and applicable progression changes. Offline scores and native replay associations are saved locally. Some failed/partial/practice outcomes have different eligibility; a missing calculation is not replaced with an invented award.

For unassisted tapping, leave Relax off. Aim assistance does not automatically mean generated taps; read [Assists](ASSISTS.md) for the distinct cursor, input and slider controls.

## Updating and moving

Close the client and back up your player data before replacing runtime files or moving the installation. Keep profiles, scores, replays and generated Map Lab files together. Do not extract a fresh package over someone else's installation without their own backup.

The clean download is a fresh-data package; it does not import the developer's account or automatically submit your offline history to a server. Live online authentication/submission remains unqualified in this candidate.
