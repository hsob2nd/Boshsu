# Features and menu guide

## Main Menu and Song Select

The Bosh shell keeps a familiar osu! flow while presenting profile identity, PP, map information, local records and contextual controls. Song Select provides Mods and Map Lab access without entering a separate application. Generated Map Lab variants share the source set's presentation while retaining their own difficulty and audio ownership.

Profiles can show an avatar, editable name, equipped title, calling card, Prestige emblem, earned name styling and fonts. These are shell/player-identity cosmetics; they do not replace skin-controlled hit objects, cursors or hitsounds.

## Mods and settings

Mods remain directly accessible. Compact estimates show hypothetical PP at useful accuracies, while PP Details exposes the deeper contributions. Actual supported mod/rate state and the selected difficulty feed the calculation.

Options group gameplay, assists, visuals, audio, performance, Map Lab, identity and world-related controls. Search provides another route to implemented settings. Key bindings are configurable; use their displayed values rather than assuming another client's shortcuts.

Map Flip is an independent Gameplay setting with Normal, Left/Right, Up/Down and Both choices. It is not part of Max Assist strength.

## Gameplay and skins

The native gameplay adapter currently accepts **osu!standard**. A taiko/catch/mania menu or inherited source component does not certify native gameplay support for that mode.

Selected skin elements remain authoritative for cursors/trails, hit circles, approach circles, sliders, combo graphics and gameplay sounds where supported. Missing elements can fall back to the provided default resources. Results intentionally combines supported skin presentation with Bosh identity/progression information.

Gameplay-only gamma, HUD visibility/scale, minimal FPS display and playfield presentation controls do not replace the selected skin. Shell scale affects the shell rather than unexpectedly resizing the gameplay field.

## Profiles and progression

Local profiles retain scores, PP systems, XP, achievements, progression and cosmetics under a stable profile ID. Editable display names and avatars are presentation properties. Cosmetic loadouts save appearance rather than gameplay skins or assistance parameters.

Prestige, Master, Legend, Ultimate and Complete presentation builds on the existing progression system. Calling cards, titles, name effects, fonts and showcases are earned/equipped through that system. Locked rewards explain their requirements where supported; this candidate does not certify every possible reward combination on every platform.

## Worlds and online

Local worlds, Server Snapshot and Server Simulation retain their existing local data boundaries. Their simulated/local values are not proof of live server rank or server-authoritative PP.

The server-provider foundation is present, but real sign-in, native score submission and replay/score equivalence remain unqualified. Offline play is the validated route. No invented leaderboard data or hidden assistance policy is promised.
